# Capturas para el portafolio

Esta carpeta está destinada a evidencias visuales del proyecto sin exponer datos reales de colaboradores, endpoints, seriales productivos ni información sensible.

## Capturas recomendadas

1. `01-formulario-principal.png` — vista general del formulario.
2. `02-validacion-colaborador.png` — resultado de una búsqueda usando datos de prueba.
3. `03-firma-digital.png` — sección de firma con información ficticia.
4. `04-confirmacion-envio.png` — mensaje de finalización usando un entorno de pruebas.

## Reglas de privacidad

- Utilizar exclusivamente datos ficticios o anonimizados.
- No mostrar números de cédula reales.
- No mostrar URLs de Power Automate ni parámetros `sig`.
- No mostrar seriales o identificadores productivos.
- Revisar cada imagen antes de publicarla.
